# Session lock and logout

Use the sidebar bottom controls to lock the terminal, log out, or open Settings. Idle lock/logout follows Session security under Manage → General settings.

### Sidebar session controls

1. Wrench opens Settings.
2. Lock keeps your user but returns to the login screen.
3. Power logout ends the session and returns to open login.

![Settings, lock, and logout on the sidebar.](images/en/session-sidebar-controls.png)

### Lock terminal

Lock is for short breaks so only the same user can unlock.

1. Tap Lock on the sidebar.
2. The login screen returns with a locked banner naming who locked it.
3. Enter the same user’s PIN or password to unlock.

![System locked banner on login.](images/en/session-locked.png)

*System locked banner on login.*

### Idle lock or logout

Session security is set by the admin under Manage → General settings and applies to every user and terminal. Until saved, the default is log out after 15 minutes idle.

1. Ask an admin (Master, or a role with General settings) to open Manage → General settings → Session security.
2. They enable the idle timer, set minutes, and choose Lock or Logout, then save.
3. When the idle limit is hit, the POS locks or logs out and shows a toast. The same user who signs back in resumes after a logout.
