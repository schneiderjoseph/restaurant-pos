# General settings

Establishment-wide settings live under Manage → General settings. Open Manage from the sidebar, then select the General settings tab. Only the Master role sees this tab by default; grant General settings to other roles in the role editor when needed.

### Open General settings

1. Sign in with Master, or another role that has the General settings permission.
2. Open Manage from the sidebar.
3. Select the General settings tab.
4. Cards on this page apply to every user and terminal at the venue.

![Manage → General settings — venue-wide configuration cards.](images/en/settings-adv-overview.png)

*Manage → General settings — venue-wide configuration cards.*

### Restaurant profile

Name, address, phone, and logo used on tickets and reports. Print templates can still override the logo or header text.

1. Open the Restaurant card.
2. Enter restaurant name, address, phone, and optional email, website, and tax ID.
3. Upload or remove the logo when needed.
4. Save (manager approval may be required).

### Currency symbol

Control whether the currency symbol is shown on screen and on printed receipts.

1. Open the Currency symbol card.
2. Toggle show in UI and/or show on receipts.
3. Save (manager approval may be required).

![Currency symbol on UI and receipts.](images/en/settings-currency-symbol.png)

*Currency symbol on UI and receipts.*

### Translate receipts

When enabled, printed receipt text follows the terminal language settings where supported.

1. Open the Translate receipts card.
2. Toggle Enabled on or off.
3. Save (manager approval may be required).

![Translate receipts card.](images/en/settings-translate-receipts.png)

*Translate receipts card.*

### Print options

1. Open the Print options card.
2. Set how many physical copies each print type should produce.
3. Set max temp/final print attempts per order (0 means unlimited).
4. Save print options when finished.

![Print copies and max attempts card.](images/en/settings-print-options.png)

*Print copies and max attempts card.*

### Active menus

1. Select which menus this terminal can sell from.
2. Save so floor staff see the correct categories and dishes.
3. Combine with Manage → Menus for full menu maintenance.

![Menus card.](images/en/settings-adv-menus.png)

*Menus card.*

### Service charges

1. Set default service charge type (percent or fixed) and value.
2. These defaults apply when service charge is used on payment.
3. Save (manager approval may be required).

![Service charges card.](images/en/settings-adv-service-charges.png)

*Service charges card.*

### Closing cycle

Defines the business-day window used for closing and day-range operations.

1. Enable a custom cycle when the venue runs overnight.
2. Set start and end times for the business day.
3. Save (manager approval may be required).

![Closing cycle card.](images/en/settings-adv-closing-cycle.png)

*Closing cycle card.*

### Auto check close

1. Enable automatic settlement of open checks at cycle end.
2. Choose whether to print and which payment type to use.
3. Save when finished.

![Auto check close card.](images/en/settings-adv-auto-check-close.png)

*Auto check close card.*

### Session security

One setting for every user and terminal. Until an admin saves it, the default applies: log out after 15 minutes idle (the same user who signs back in resumes).

1. Open the Session security card.
2. Enable idle protection if terminals should lock or log out after inactivity.
3. Set idle minutes and whether the action is lock or logout.
4. Save. The rule applies venue-wide to every user and terminal.

![Session security card (venue-wide).](images/en/settings-adv-session-security.png)

*Session security card (venue-wide).*

### Auto clock-out

1. Enable automatic clock-out for labor accuracy.
2. Choose triggers: shift end, defined time, or both.
3. Save when finished.

![Auto clock-out card.](images/en/settings-adv-auto-clock-out.png)

*Auto clock-out card.*

### Show inclusive prices

When enabled, menu and order UI can display tax-inclusive prices according to venue tax configuration.

1. Open the Show inclusive prices card.
2. Toggle Enabled on or off.
3. Save (manager approval may be required).

![Inclusive price display toggle.](images/en/settings-show-inclusive-prices.png)

*Inclusive price display toggle.*

### Inventory settings

1. Configure inventory-related device preferences used by stock flows.
2. Save when finished.
3. Deep inventory documents live under the Inventory sidebar.

![Inventory settings card.](images/en/settings-adv-inventory.png)

*Inventory settings card.*

### Items visibility

Per-terminal display options for menu search, cart totals, and order cards. Changes apply immediately on this device.

1. Open the Items visibility card.
2. Under Menu: enable dish search, search type (number vs both), and show dish numbers.
3. Under Cart: show or hide totals in the cart.
4. Under Orders: show or hide totals and other order-card fields as listed.
